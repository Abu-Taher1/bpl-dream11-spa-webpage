# 🏏 Cricket Player Choice App
(PH-B13-Milestone6)

A simple, fully responsive web application built to learn and practice raw React fundamentals.

## 🎯 Learning Goals
* **useState:** For managing the player roster.
* **useEffect & API:** For fetching and connecting player data.
* **Props Drilling:** For passing data between components.

## ✨ Features
* **Select Players:** Choose up to 6 players of your choice.
* **Remove Players:** Easily remove players from your list.
* **Responsive:** Works perfectly on any device or screen size.

## 🛠️ Tech Stack
* React + Vite
* Tailwind CSS + daisyUI
* React Icons
* React Toastify

## 🚀 How to Run
1. Run `npm install` to install dependencies.
2. Run `npm run dev` to start the app.
